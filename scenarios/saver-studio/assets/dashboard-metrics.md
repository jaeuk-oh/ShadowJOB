## 읽어내야 할 신호 (채점·골든셋용, 사용자 비노출)
- 지표 악화의 **변곡점이 W4(환불정책 변경 주)** → 환불 카테고리 미해결 폭증과 인과.
- 환불 미해결은 **응답시간 문제 아님**(대부분 빠름) → 내용(오답) 문제 = 지식베이스 공백.
- 별개로 **피크 시간대 응답시간 급증** = 인프라/스케일링 문제(결제·일반 문의에 영향).
- 두 원인은 **분리**되어야 하며 우선순위가 다르다.
